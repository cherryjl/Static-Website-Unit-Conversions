# Unit Converter

A fast, user-friendly web application for converting between various units of measurement. Perfect for cooking, construction, travel, and more!

## Features

- **Multiple Conversion Categories**
  - Cooking (teaspoons, cups, liters, etc.)
  - Construction (inches, feet, meters, etc.)
  - Travel (mph, kmh, etc.)
  - Health & Weight (pounds, kilograms, etc.)
  - Technology (bytes, megabytes, gigabytes, etc.)
  - Time (seconds, minutes, hours, days, etc.)

- **Quick Reference Tables** - Pre-built conversion charts for common conversions on each category page

- **Custom Converter** - Convert any value between units with a responsive input/output interface

- **Dark Mode** - Toggle between light and dark themes for comfortable viewing in any lighting

- **Email Suggestions** - Built-in form to send conversion suggestions directly to the developer via your default email client

- **Responsive Design** - Works seamlessly on desktop and mobile devices

## Technologies Used

- **HTML5** - Semantic structure
- **CSS** - Responsive styling with flexbox
- **JavaScript** - No frameworks or dependencies
- **Service Workers** - PWA support for offline functionality

## Getting Started

No installation required! Simply clone or download the repository and open `index.html` in a web browser.

## Features Details

### Dark Mode

Click the sun/moon icon in the header to toggle between light and dark themes. Your preference is saved locally.

### Custom Converter

Each category page features a custom converter that:

- Converts any value between available units
- Rounds results to 2 decimal places
- Displays helpful error messages for invalid input

### Email Suggestions

Found a missing conversion or have feedback? Use the suggestions form to draft an email with pre-filled content and send it through your default email client.

## Course Information

This project was created for IT 301 and was born from a simple need: getting tired of looking up measurement conversions while cooking!
